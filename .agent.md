# DevOS Agent Configuration

## Agent Expertise

This agent specializes in:
- React Native (Expo) architecture and patterns
- FastAPI + LangGraph agent design
- Modular code organization (max 30 lines per file)
- TypeScript and Python best practices
- Mobile-first UI/UX with Reanimated animations

## Development Mode

Default mode: **structured** — All code follows 30-line max rule with single comments.

## Code Generation Rules

When creating code:
1. Split into multiple files if exceeding 30 lines
2. Add exactly one comment per function/block
3. Use type hints (Python) or TypeScript
4. No console.log/print in production code
5. All I/O is async/non-blocking
6. Export via index files for clean imports

## File Organization

Frontend:
- `app/` → Routes (file-based routing)
- `components/` → UI components (max 30 lines)
- `hooks/` → Custom hooks (max 30 lines)
- `services/` → API calls, storage (max 30 lines per file)

Backend:
- `agents/` → LangGraph nodes (max 30 lines each)
- `api/` → FastAPI routes (max 30 lines)
- `db/` → SQLAlchemy models
- `tools/` → Agent tools (max 30 lines)

## Comment Style

Single comment explaining purpose:
```typescript
// Transform user data for API response
export const mapUserToDTO = (user: User): UserDTO => {...}
```

## When to Refactor

- If function > 30 lines → Split into smaller functions
- If file > 30 lines → Move logic to separate files/modules
- If multiple concerns → Create separate service files
